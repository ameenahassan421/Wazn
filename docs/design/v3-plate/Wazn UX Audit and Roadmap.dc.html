UX audit & build roadmap · August 2026

From workout log to workout partner.

Scope: the shipped Wazn PWA (repo ameenahassan421/Wazn), evaluated against its own stated job — a set logged in under 30 seconds, one hand, mid-workout — and against Hevy, the app it must replace.

01 · Verdict

Strong engine, wrong cockpit.

The engineering is genuinely solid: offline write queue, workout checkpoint that survives crashes, per-user device reconciliation, RLS, a real 3,200-set training history. The UX problem is structural, not cosmetic — the app is organized around its code (five equal tabs, one per module) instead of around the lifter's day (get in, lift, get out, feel progress).

The coach — the one thing Hevy cannot copy at Wazn's price — is a destination you have to visit, not a partner who shows up. The redesign inverts both: one home feed with one Start action, and the coach woven into every moment that matters.

02 · Findings, by severity

Ten findings. Every fix already designed.

S1

Starting a workout has no obvious door

The Log tab opens on a form, with routines below the fold. The single most frequent action in the app is not the single most visible thing. Fix: home feed with one vermilion Start (screen 01).

S1

The coach is invisible when it matters

AI advice lives on the 4th tab; mid-workout — the moment you asked for a buddy — it says nothing. Fix: one coach line above the log button, a companion on the rest screen, a debrief at finish (02, 03, 05).

S2

Five equal tabs for five unequal jobs

Log is daily; History, Progress, Coach, Friends are occasional. Equal tabs make the app feel bigger and harder than it is — your "hard to navigate." Fix: one feed, secondary surfaces behind chips (01).

S2

No set types, no supersets

The schema stores set_type and RPE but the UI never exposes them — a hard blocker for replacing Hevy. Fix: set-options sheet (13).

S2

Rest is separated from logging

The timer is a control you operate, not a rhythm the app keeps for you. Fix: auto-start on log, per-exercise duration, lock-screen live activity (03, 13, 15).

S2

Destructive actions are buried

Discard-workout only exists inside the header overflow menu (the code's own comments record a user failing to find it). Fix: explicit finish flow with visible, two-tap discard (05).

S2

No finish moment

A workout ends with a state change, not a feeling. PRs deserve iron, and the session deserves a summary. Fix: finish screen with stats, PR plate, coach debrief (05).

S3

Header rents prime space to rare actions

kg/lb and language toggles sit in the header on every screen; both are set once. Fix: Settings (14).

S3

Progress is a chart, not an answer

A 1RM line with no interpretation. "Am I getting stronger?" should be answered in words. Fix: insight card + PR log under the chart (07).

S3

Friends costs a tab it hasn't earned

You called it pointless; for a solo lifter it is. Fix: retire the tab; revisit social as shared PRs/share cards later (05's share card is the seed).

03 · What the redesign keeps sacred

  • A set logged in under 30 seconds, one hand — the flow is never interrupted, never paywalled.
  • Weight stored in kg, always; lbs display-only.
  • Terse gym-partner voice. PRs get iron, not confetti.
  • Arabic soul: the وزن barbell mark leads in the Arabic locale; RTL is a flip, not a rewrite (16).
  • One accent color, earned. If two things are vermilion, one is wrong.

One conscious break: the old system was dark-only for gym lighting. The new identity is light by default (your call — easier on the eye), but Workout-adjacent surfaces (Rest, lock screen) stay dark. A "gym mode" that darkens the live workout is on the roadmap to test.

04 · Roadmap

Quick wins first, identity second, platform third.

P0

Quick wins — current codebase, 1–2 weeks

  • Coach brief card at the top of the Log tab (CoachBrief exists — move it, don't build it).
  • Plate calculator inside set entry (LoadHelper already computes it — surface it).
  • PR moment in FinishSummary: the plate badge + est. 1RM delta.
  • Move kg/lb + language into a Settings surface; make discard visible in the finish flow.
  • Auto-start rest on set log, default 2:00.
P1

Core loop redesign — 3–5 weeks

  • Home feed replaces the tab bar (screens 01, prototype). Chips route to History / Progress / Coach.
  • New workout + rest + finish screens (02, 03, 05); coach lines from the existing coach.ts pipeline.
  • Set types, supersets, RPE, per-exercise rest (13) — schema already supports all of it.
P2

Identity & growth — 3–4 weeks

  • Plate logo rollout: app icon, splash, favicon, share cards (brand sheet).
  • Routines + "coach builds your week" (11); exercise detail with how-to (12).
  • Hevy import as a first-run flow, not a CLI script (09, 10) — the switching moment.
P3

Platform — ongoing

  • Arabic RTL flip (16) — the logical-properties groundwork is already in the codebase.
  • Lock-screen live activity / widget via the Capacitor wrapper (15).
  • Body measurements (14), gym dark mode, share-card social seed.

05 · How we'll know it worked

Open → first set

Median seconds from app open to first logged set. Target: under 30.

Routine starts

% of workouts started from a routine or coach plan, not empty.

Import completion

% of Hevy switchers who finish the import — the moat metric.

Week-4 retention

Lifters still logging in week 4 — the only number that decides the Hevy question.
