# Handoff: Wazn Design v2.1 — the missing screens

## Overview

Extends **v2 "Loaded Ink, refined"** with the four surfaces the launch
bundle requires and the v2 handoff never covered:

1. **Coach** — the AI tab (Coach's Notes + routine builder)
2. **Progress** — the full dashboard (this-week, muscle balance, volume
   trend, strength list)
3. **Friends** — weekly leaderboard + feed with likes
4. **Finish** — workout summary + the 4:5 shareable card

Every token, radius, elevation rule, motion rule, and voice rule from v2
applies unchanged. This file adds screens, not a new system. `Wazn
Missing Screens.dc.html` opens directly in a browser; it is a design
reference to recreate in the codebase (React + Vite + Tailwind, logical
properties, existing tokens in `src/index.css`), not production code.

## Fidelity

High-fidelity. Colors, type styles, spacing and component anatomy are
final; exact pixel values in dense phone layouts may flex ±2px per v2's
card-padding rule.

## Information architecture change

Tab bar grows from three items to FIVE:
`Log · History · Progress · Coach · Friends`
Active state, height (58–60px), and top-rail treatment unchanged. Coach
uses the star glyph, Friends the two-figure glyph (inline SVG set,
24 grid, stroke 2, per v2 iconography rules; directional icons only
flip in RTL — these don't).

## Screen rules (see spec columns in the HTML for full anatomy)

### 01 Coach

- Two bounded tools, NO chat surface anywhere.
- Coach's Notes: 3–5 notes, each = index (12 mono amber) + headline
  (15/600) + support (13/400 n2) + **data chip** (mono 11, amber-300 on
  7% tint) quoting the exact numbers behind the insight. Only note #1
  carries the 4px inline-start knurl band.
- Routine builder: dashed-amber card, three single-select chip rows
  (goal / days / equipment), ONE hero button: "Generate routine".
  Result = full-screen preview → Save routine (hero) / Adjust
  (secondary). Saved routines are ordinary editable routines; never
  auto-activate.
- Footer micro: "AI-generated · not medical advice · N regenerates left
  this week". Quota-spent state disables Regenerate at 45% opacity.
- Loading: kicker text "READING YOUR LOG…" — no skeletons, no spinners.
- Empty (<3 workouts): "Log 3 workouts and the coach will have
  something to say."

### 02 Progress

- This-week card: sessions / volume / streak, rule-split, 27/600 tnum,
  streak plate-bars from v2.
- **Muscle balance (signature):** per-group tracks with the 10–20
  target band drawn in knurl at 33–67% of track (scale caps at 30
  sets). Fill semantics: under = n5 neutral, in-band = amber 500,
  over = amber 800. Single hue carries all three meanings. No red.
- Focus callout on 7% tint names lagging groups and links to Coach.
  Computed in SQL; the AI only phrases it.
- Volume trend: v2 chart grammar (amber 2px, 8% area, dashed 2/4 grid,
  last-point dot), one point per week.
- Strength list: initial tile/thumb, name + last-session micro, e1RM
  20/500 tnum, 4-week delta in mono (▲ amber / ▼ n3 / → n5). Rows open
  the existing exercise detail page.
- Empty: zeros + unfilled knurl bands + "Log a workout to load the
  bar." Never fake data.

### 03 Friends

- Leaderboard card crowned with a 6px knurl band (the screen's only
  knurl). Your row on 7% amber tint with amber rank. Volume metric
  only at launch.
- Feed cards: initial tile, name + routine, timestamp micro, PR badge
  only when earned; three rule-split stats (duration / volume / sets);
  fact line quotes the best moment; like = outline heart → filled
  amber + mono count. One tap. No comments.
- Empty: leaderboard of one + "Invite someone to chase." Invite =
  share-sheet link.
- Renders only what RLS allows: finished-workout name, duration,
  volume, PRs. Never per-set data in the feed.

### 04 Finish + share card

- Summary: routine/date kicker, three display figures, PR rows on
  amber tint with knurl badge. Hero = "Share card", secondary "Done".
- Share card: 1080×1350 canvas → native share sheet. Anatomy:
  wordmark (bar + WAZN), giant figure 56/600 tnum (volume — or the PR,
  which replaces it as hero when one fell), mono session kicker, 8px
  knurl divider, three-stat grid, footer NAME · DATE (mono, n3) and
  TRYWAZN.APP (mono, amber-700). Pure tokens; exports pixel-identical
  to the in-app preview. No photos, no emoji.

## RTL

All four screens use logical properties throughout; the knurl bands,
tracks, and stat splits mirror automatically. Figures stay Latin
tabular digits in isolated dir="ltr" spans per v2 §RTL. Chart x-axes
do not flip (time reads left→right in both scripts — same rule as
clocks/trends in v2 iconography).
